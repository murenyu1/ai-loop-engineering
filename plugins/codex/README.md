# AI Loop Codex 插件 4.2

一次安装后，在不同 Codex 本地项目使用开发闭环、分页记忆、中断恢复、模型面板与工作区自动入口。本包已包含所需核心，无需再下载通用工作流。

## 安装

需要已登录的 Codex 与 Node.js 18+。在本包根目录、普通用户终端执行：

```text
node scripts/install-plugin.mjs --project .
node scripts/install-plugin.mjs --project . --apply
```

先预演，再安装。安装器调用 Codex 原生插件命令，不改 settings.json 或钩子信任缓存。安装后新会话核对技能加载。

## 日常使用

运行 `open-console.ps1`（Windows）或 `node scripts/console.mjs`，直接打开本机管理界面：

1. 输入项目真实绝对路径并登记，打开工作区开关。
2. 选择工作区和全局/项目范围，修改角色模型、支持的思考深度与并发后保存；项目可恢复继承全局。主会话模型在 Codex 自身选择器修改。
3. 在 Codex 原生 `/hooks` 审核并信任本插件的 SessionStart 定义，再在登记的精确项目根新开聊天。直接发送下一条开发指令，AI 会先按工作流读取必要记录。

面板的地址包含临时凭据，不能分享。仅监听 127.0.0.1，无远程托管；页尾“关闭管理服务”可退出，之后重新运行入口即可。配置在原生重载后的后续派发生效，正在运行的代理不变。钩子未信任或被组织策略禁用时，不会自动注入；仍可显式使用插件技能。

原生插件详情页只提供聊天入口；自定义模型表单位于这个本机面板。工作区登记只选择启用范围，不授予 AI 新的提交、发布或越权操作许可。

每个项目只存自己的 `.ai-loop/`。中断后根据已落盘摘要、未关闭工作单元与关键文件恢复，不能恢复未记录的讨论。旧项目入口/同名代理冲突须先合并；不覆盖人工修改，不批量调整 Windows 权限。

完整设计、通用工作流下载和维护源码见 [项目首页](https://github.com/murenyu1/ai-loop-engineering)。
