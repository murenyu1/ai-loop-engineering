## 实现

- core/scripts/execution.mjs 将独立报告关联至本运行 activity 的执行记录，核对真实原生 ID/宿主、不同父子上下文、任务/角色/批次、完成观察、revision 与原生证据摘要；开发者上下文不能作为独立评审者。最终评审另用 final 执行记录。主代理有写权限时仍可能伪造日志，此处是证据关联，不是身份认证。
- 新独立运行自动声明 execution_evidence=required、使用 schema 4，每次验证/评审递增批次；旧核心拒绝写入。旧运行历史保持不变，继续提交 independent 报告时同样核对执行证据，不补造历史调用。
- project_path 明确运行归属，默认快照取该子目录，snapshot_paths 可纳入共享依赖；记录保持工作区扁平 runs 兼容结构。bootstrap --project-path 精确筛选，DSH/Codex 看板显示子项目归属，Windows 范围匹配考虑大小写。
- DSH 区分主/叶角色及 lite/关闭状态。ai_loop_prepare 返回一次性当前会话凭据，经原生工具登记 requested 后交给 delegate，启动前消费；重载不会复用旧 requested 重派。ai_loop_observe 返回真实内存观察，主代理通过获准原生工具持久化状态/证据；宿主不直接写项目。冷恢复缺少观察时仍须核对原生执行者，不能猜测停止。
- DSH 客户端声明并订阅原生 sessions/workspaces 服务；只有 phase=ready/state=idle 且无错误的完整快照才能对账删除，空成功列表不会复活历史项目，加载/失败保持配置。总开关参与绿红点，草稿提示未保存；会话异步加载及切换未知会话不会继续选旧目标。本机宿主公开工作区 controller 的 baseline/错误/订阅行为已只读核对，界面尚待真实宿主验收。
- 通用 ZIP 从安装器 REQUIRED_FILES 构建，携带安装器/doctor/全部依赖；独立解包验证脚本可运行。Codex 使用原生 loop-* 与当前会话工具，新增证据保存协议，不伪造一个 MCP 启动器替代它。Cursor/Pi/generic 仍明确仅适配入口；完整 DSH 多代理使用 DSH 插件。
- 安装只读预演进一步发现本地市场正常版本升级被误判为人工修改。安装器现仅在旧插件所有受管文件摘要有效、旧市场版本与已登记旧 bundle 版本一致、其他元数据完全相同时允许更新版本号；来源路径等人工修改继续阻断。新增不写真实配置的升级/拒绝覆盖回归。此修复晚于首轮与上一最终候选回归，必须再次验证包含修复的新快照。
