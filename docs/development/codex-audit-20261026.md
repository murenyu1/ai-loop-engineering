# Codex 循环回归修复与功能审计

日期：2026-10-26。开发分支 dev/codex，基线 07adf7a。用户确认实施方案及完整功能检测矩阵；先检查循环遗留文件，再开发。未发现循环新增的磁盘垃圾，重复内容是聊天消息及侧栏实例；未删除历史记录、安装日志或源文件。

## 事故与验证缺口

旧版自动定位调用带UI资源的 ai_loop.dashboard，再发送聊天消息要求模型回调同一渲染工具。新实例拥有独立的locating和binding，单实例防重不能阻断跨实例循环。页面初始化、刷新与保存后读取也错误复用渲染入口。此前VM测试只模拟structuredContent，遗漏宿主处理resourceUri时创建或重挂载页面的副作用。

本轮离线宿主夹具依据真实工具描述符与实际协议返回处理UI资源：历史最小故障链路在实例数上限内复现扩张和自动消息；新版首开、重复初始化、切页、刷新、保存、轮询、关闭及重开均校验面板数与消息数。测试消息全部由夹具截获，不发送至真实聊天。

## 实施结果

1. 新增无UI资源的数据工具 `ai_loop.dashboard.read`。显式入口 `ai_loop.dashboard` 保留打开能力；两者共享校验与投影，参数不再被原地修改。旧binding仅保留兼容，不再由新页面生成。
2. 删除自动定位聊天消息和模型回调链路；所有页面内读取改调数据工具。初始化单次执行，相同宿主输入幂等，后台发现合并在途请求，关闭时停止轮询、拒收迟到响应并解除监听。
3. 参考DSH的单份工作区选择与上下文适配。DSH通过宿主scope.sessionId/cwd及会话列表订阅取得归属；Codex只接受可信工具输入、通知和服务端校验的显式root/session。空入口没有这些数据时明确未定位，保留手选；不能声称已实现无上下文自动定位，不能用最近项目或插件cwd替代。
4. 修复真实桌面has_user_event默认0造成最近使用时间全空：优先识别明确顶层source，排除subagent JSON、guardian及无role/path的代理来源；未知来源保守降级，旧schema允许真实用户标志后备。零recency回退至正updated时间。无法读取数据或无法识别活动时明确提示稳定退化，不再静默冒称最近使用排序生效。
5. 修复恢复默认忽略成员配置基线：设置入口检查集中、全局继承及成员快照；事务在逐成员清理、提交前后复核，外部改动保留。新增用例先在旧实现复现未拒绝冲突，修复后通过；另覆盖最后成员及提交前新增外部配置。
6. 修复无关运行损坏JSON导致有效聊天历史不可读：隔离无效JSON或分页间移除的记录，返回unreadable_count并显示提示；权限与其他验证错误继续显式抛出，不吞掉或绕过。聊天隔离与分页游标仍按原契约。

## 独立评审补修

首次沙箱评审因用户级Git ignore读取权限提示中止，原始BLOCKED保留；主代理通过平台授权在正常用户宿主执行同一只读Git检查，退出0且未修改配置或权限，随后重新派发独立评审。
