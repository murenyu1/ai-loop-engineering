## 已确认缺陷及修复

1. 仅登记启用的宿主工作区没有项目 profile 时，设置页继承全局，doctor、启动钩子、登记策略和看板却默认全部关闭。统一在 resolveWorkspaceProfile 解析默认继承；读取不写入配置，未配置仍关闭，显式项目关闭不回退。
2. 启动钩子未验证成员冲突，会将冲突误报为关闭或已开启。改用 resolveEffectiveProfile，冲突与损坏明确阻断。
3. CLI status 忽略工作区身份；项目 set/configure/reset 只改根文件，留下过期集中登记。改用工作区解析和事务，覆盖全部成员，并提供只读预演；未知目录保留兼容。
4. 安装升级新增路径与未登记本地文件碰撞时可能覆盖。安装前完整校验并拒绝碰撞。
5. 集中 profile、成员 profile 与物化登记存在静态矛盾时，设置页漏报冲突。统一对三者比对；原生设置允许显式恢复已读取的静态冲突，全部并发摘要和版本校验仍保留。
