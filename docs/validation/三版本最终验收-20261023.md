## 原发现与修复对应

1. **零子代理记录也能独立通过**：增加 execution_id 与 activity 的原生 ID、宿主、独立父子上下文、任务/角色/attempt、revision、完成观察和证据摘要关联；最终评审使用独立 final 记录。保留旧历史，不补造原生调用。
2. **DSH 主/叶代理提示冲突**：区分主代理与叶角色，结合 lite、角色开关及多代理要求生成提示；叶代理不得再次派发。
3. **DSH 持久记录与冷恢复**：prepare 返回当前会话一次性凭据，先经获准工具登记 requested，delegate 消费后真实启动，再用 observe 核对并持久化。冷重载不复用旧票，不把过期观察当成已停止。宿主插件不直接绕过权限写项目。
4. **工作区部分列表误删、空列表复活**：仅完整 ready/idle、无错误快照允许清理；成功空列表与加载/失败区分；原生会话与工作区保持订阅。
5. **点色与目标绑定**：有效点色合并全局/工作区开关，标明未保存草稿；切换未知会话先清旧目标，异步解析后才绑定。
6. **core 独立包入口不完整**：通用包携带安装器及 REQUIRED_FILES 依赖，更新 SETUP 与能力矩阵；支持环境走原生发现和调用验收，其他入口明确能力范围，不能把指令模式称为原生多代理。
7. **Codex 适配**：保留原生 loop-* 角色与当前会话委派工具，补充配置检查、角色启用、调用证据与恢复协议；没有照搬 DSH 的委派工具或 UI 插槽。
8. **子项目范围与恢复**：新增 project_path/snapshot_paths 与筛选，工作区集中存储运行、按子项目归属；Windows 大小写比较覆盖 bootstrap 双入口及 listRuns，POSIX 保持敏感，unknown 条目安全排除。
9. **安装升级误判**：旧受管文件和元数据完整时允许正常市场版本升级；其他人工修改继续拒绝覆盖。

独立评审曾连续发现目录大小写、跨平台测试夹具及列表遗漏，均使用真实开发子代理修复，并重新测试及复评。修复预算已用 **3/3**；当前没有新增源码缺陷待修。
